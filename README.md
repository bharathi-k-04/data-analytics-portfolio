# Data Analytics Portfolio

This repository contains a collection of data analytics projects covering statistical analysis, SQL analytics, machine learning and data visualization.

## Projects

1. **[Austo Motor Vehicle Analysis](./austo-motor-vehicle-analysis)** — EDA on vehicle preference and marketing strategy for an automobile manufacturer.
2. **[Applied Business Statistics](./applied-business-statistics)** — Probability, hypothesis testing, and ANOVA across four independent business case studies.
3. **[ShowTime OTT Viewership Prediction](./showtime-ott-viewership-prediction)** — Linear regression to predict first-day content viewership for a streaming platform.
4. **[Car Crash Survival Prediction](./car-crash-survival-prediction)** — Classification modeling (Logistic Regression vs. Decision Tree) for road safety policy.
5. **[Employee Promotion Prediction](./employee-promotion-prediction)** — Ensemble classification with class-imbalance handling for an HR promotion pipeline.
6. **[AllLife Bank Credit Card Segmentation](./alllife-bank-credit-card-segmentation)** — Unsupervised clustering (K-Means & Hierarchical) for customer segmentation.
7. **[New Wheels SQL Analytics](./new-wheels-sql-analytics)** — SQL-based business analytics answering 10 leadership-level questions for a vehicle resale platform.
8. **[Boston Condo Price Analysis](./boston-condo-price-analysis)** — Tableau storyboard analyzing the drivers of condo pricing for a real estate recommendation system.

## Skills & Tools
Python (pandas, NumPy, scikit-learn, statsmodels, SciPy), SQL, Tableau, statistical testing, machine learning (regression, classification, clustering), data visualization.
